# 实验报告素材

以下文字可根据实际运行情况调整后填写到实验报告。课程资料为虚构样例；已在智谱GLM-5.3-Flash上在线验证一条截止日期查询，但尚未系统测量模型路由准确率或完成全部真实多轮场景验证。

## Agent介绍参考文本

本实验实现个人学业与日程管家Agent，采用Python命令行界面与标准Function Calling流程。模型依据系统提示词和两个工具的JSON Schema，选择工具并生成结构化参数。course_rag_search从本地课程Markdown与任务列表中检索评分标准、作业要求、考试及截止日期，并返回资料来源；calendar_scheduler读取ICS日历，展开重复事件，检查忙闲时间，结合截止日期、优先级、学习时长和休息间隔生成排期。时间不足时返回剩余任务，支持用户调整后重新安排。上下文集成包括检索片段、日历工具结果、多轮对话历史、当前日期和用户偏好。完整预览可由用户保存并导出ICS。系统使用严格Schema与本地参数校验，记录工具调用过程，支持复现和分析。

## 运行说明参考文本

安装Python依赖后，运行main.py demo可查看离线脚本演示：查询软件工程评分、检索下周考试、尝试在两个晚间排期、发现时间不足、调整可用时间和课程范围，最后保存并导出ICS。该模式真实执行本地工具，但不调用大模型。配置OPENAI_API_KEY与OPENAI_MODEL后，运行main.py --trace chat进入真实多轮对话；trace展示模型生成的工具名、参数及工具结果。排期先生成预览，输入/commit及plan_id后写入本地日历，后续安排会避开已保存的学习块。运行记录保存在runs目录，可用作工具调用与上下文传递的分析材料。

## 建议运行截图

1. 真实API模式下的单工具查询：问题、模型产生的course_rag_search参数、查询结果及来源。
2. 多工具协作：查到考试后调用calendar_scheduler；显示忙碌日程和时间不足的结果。
3. 用户补充优先级和可用时间后，Agent引用会话上下文重新生成排期。
4. /commit保存成功、导出的confirmed ICS，以及日历软件导入后的学习块。

若还未配置API，可先截离线工具运行图，但必须标明“脚本演示”，不能将其描述为模型自主路由证据。

## 使用AI完成实验的过程素材

可如实记录本次开发中AI协助完成的部分：拆分模块、设计两个严格工具Schema、编写系统prompt、实现词项检索和日历排期、编写测试并定位问题。实际遇到的问题包括ICS固定偏移时区不能正确读回，修正为UTC写入、北京时间显示；另一个问题是开发环境默认临时目录权限受限，测试改为在项目内隔离目录运行。测试覆盖了全天事件、重复事件例外、截止时间、休息间隔、过期预览、重复保存及工具调用上下文。

真实模型还暴露了把JSON null输出成字符串"null"的问题，导致日期解析错误和重复重试。修复方式是在Schema允许为空的字段中统一转换空值、在参数校验中检查日期格式，并在相同错误重复出现时停止重试。线上复测这条截止日期查询只调用一次课程工具，未再出现错误。其余意图识别或消歧问题，应在运行后记录具体输入、错误工具调用和修正方式，不预先编造实验结论。
